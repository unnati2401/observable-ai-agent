# Observable AI Agent

> Observe AI Agents like Distributed Systems using OpenTelemetry.

## Overview

This project demonstrates end-to-end observability for AI agents using:

- Go
- OpenTelemetry
- Grafana
- Tempo
- OpenTelemetry Collector
- Podman Compose

The objective is to trace every stage of an AI request—from planning and tool execution to LLM inference—using distributed tracing.
